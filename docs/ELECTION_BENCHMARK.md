# Election-domain benchmark

## Is the CrowdFlower GOP-debate dataset appropriate for 3-class sentiment evaluation?

**Verdict: yes, as a secondary, transfer-only benchmark, with the caveats below.**
It is never used for training, early stopping or model selection.

| Criterion | Finding |
|---|---|
| Label space | Exactly `Positive / Negative / Neutral` (8,493 / 3,142 / 2,236 raw). Maps 1:1 to TweetEval. |
| Label definition | Annotators judged the sentiment of the tweet as a whole, which matches SemEval-2017 Task 4A "message polarity". Manual inspection of 40+ high-agreement examples per class: *Neutral* = news links, announcements, viewing logistics; *Negative* includes sarcastic praise ("Love to see men … talk about what I can do with my body ❤️"), which is consistent with TweetEval's convention. |
| Not stance | Labels are sentiment, not candidate support: e.g. "Thank you @tedcruz for calling out the #Rhino's" is Positive although it attacks other Republicans. The app states this distinction. |
| Domain | Real election tweets (Aug 6–7 2015, first Republican primary debate, `#GOPDebate`). All rows marked relevant. |
| Leakage | After normalisation, 1 tweet overlaps TweetEval train and 0 overlap validation/test. |
| Duplicates | 7,686 of 13,871 rows (55%) are retweets. De-duplication by `dedup_key` keeps the highest-agreement copy, drops copies with conflicting labels, and leaves **9,222** unique tweets. |
| Annotation agreement | `sentiment_confidence` (trust-weighted agreement) is bimodal: 5,367 raw rows = 1.0, almost all others ≤ 0.75 (median 0.68); only 17 raw rows lie in (0.75, 1.0). About 40% of rows have agreement ≤ 0.70, so the full set contains substantial label noise. |
| Class balance | Skewed negative: 59% (full, de-duplicated) and 71% (high-agreement subset). Accuracy is therefore inflated by the majority class; **macro-F1 is the headline metric**. |
| Limitations | One event, one party's primary, 2015 vocabulary, US-only; candidates' names appear in TweetEval 2016–17 data in different contexts. Not representative of 2024+ election discourse. |

### Pre-registered evaluation protocol
Fixed in `sentiment.data.GOP_HIGH_AGREEMENT_THRESHOLD` before any model was evaluated:

* **GOP-full**: all 9,222 de-duplicated tweets.
* **GOP-high-agreement**: the 3,589 de-duplicated tweets with `sentiment_confidence = 1.0`.
  Distribution: 71.1% negative, 14.3% neutral, 14.7% positive.

Both are always reported, separately, with 95% bootstrap CIs, per-class F1, per-candidate accuracy and
a paired bootstrap against the original model.

### Classical-baseline transfer (completed, CPU)
Validation-tuned TF-IDF (word 1–2 + char 2–5) + LinearSVC(C=0.1, balanced):

| Dataset | n | Accuracy [95% CI] | Macro-F1 [95% CI] | Macro-recall |
|---|---:|---|---|---:|
| TweetEval validation | 2,000 | 70.45 [68.35, 72.40] | 67.97 [65.63, 70.22] | 68.54 |
| TweetEval test | 12,284 | 63.16 [62.25, 64.03] | 62.62 [61.68, 63.54] | 63.28 |
| GOP-full | 9,222 | 55.35 [54.37, 56.40] | 50.49 [49.44, 51.57] | 52.09 |
| GOP-high-agreement | 3,589 | 64.34 [62.72, 65.84] | 55.32 [53.42, 57.11] | 60.06 |

General-tweet performance does **not** transfer to election tweets: macro-F1 drops about 12 points from
TweetEval test to GOP-full. Neutral (F1 0.38–0.43) and positive (0.42–0.52) suffer most. Transformer
results will be filled in by the Colab run.

## A modern, hand-labelled election set (designed, not yet built)
The GOP set is real but dated. For 2024-era text, use the guidelines below. **No labels have been
created yet**, and none should be generated by a model and then presented as gold.

1. **Sample** 600 posts stratified by source (candidate accounts, news outlets, ordinary users) and
   topic, 2023–2025. Remove duplicates with `dedup_key` and check for overlap with all training data.
2. **Label** the *author's expressed sentiment in the post as a whole*:
   * *Positive*: approval, praise, hope, enthusiasm, gratitude.
   * *Negative*: criticism, anger, fear, mockery, sarcasm whose intended meaning is negative.
   * *Neutral*: factual reporting (including reporting of negative events without evaluation),
     questions without evaluative tone, logistics, or genuinely balanced mixed content.
   * Sentiment ≠ stance: "Candidate X destroyed Y in the debate!" is Positive (enthusiasm).
3. **Three independent annotators**, gold = majority. Report Fleiss' κ; keep a "no majority" bucket
   and exclude it from accuracy but report its size.
4. **Freeze** the set (hash it) before running any model on it; evaluate each model once.
